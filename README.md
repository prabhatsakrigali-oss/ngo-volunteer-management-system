# NGO Volunteer Management System

A web-based NGO Volunteer Management System built using Node.js, Express.js, MongoDB, and EJS.

## Features

* Admin Authentication
* Volunteer Registration
* Volunteer Management
* Group Management
* Attendance Tracking
* Event Management
* Gallery Management
* Donation Tracking
* Career Applications
* Certificate Generation
* QR Code Verification
* Password Reset via Email
* Dashboard and Reports

## Tech Stack

* Node.js
* Express.js
* MongoDB
* Express
* EJS
* Bootstrap
* Nodemailer

## Installation

```bash
npm install
npm start
```
