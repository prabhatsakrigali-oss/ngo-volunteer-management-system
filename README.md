# 🌍 NGO Volunteer Management System

A Full Stack **NGO Volunteer Management System** built using **Node.js, Express.js, MongoDB, Docker, and Kubernetes** to efficiently manage volunteers, donations, groups, attendance, certificates, and administrative operations.

This project demonstrates real-world full-stack development combined with DevOps practices for deployment and scalability.

---

# 📌 Project Overview

The NGO Volunteer Management System is designed to help non-governmental organizations manage volunteers and activities through a centralized web application.

The system provides secure authentication, volunteer registration, group management, donation tracking, attendance management, reporting, and certificate generation.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/prabhatsakrigali-oss/ngo-volunteer-management-system.git
```

---

## Move into Project

```bash
cd ngo-volunteer-management-system
```

---

## Install Dependencies

```bash
npm install
```

---

## Start Application

```bash
npm start
```

---

# 🐳 Docker Deployment

## Build Docker Image

```bash
docker build -t ngo-volunteer-management-system .
```

## Run Docker Container

```bash
docker run -p 3000:3000 ngo-volunteer-management-system
```

## Docker Compose

```bash
docker-compose up --build
```

# ☸️ Kubernetes Deployment

Deploy the application using Kubernetes.
